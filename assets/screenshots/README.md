# 截图目录

把用微信开发者工具模拟器截的小程序页面图放到这里，文件名与根目录 `README.md` 中引用的一致即可：

| 文件名 | 建议内容 |
|--------|---------|
| `launch.png` | 启动页（趣说干支，两个入口） |
| `bazi.png` | 干支历法页（输入 + 干支结果） |
| `chart.png` | 生肖属相页（年份 + 生肖结果） |
| `mingpan.png`（可选） | 生成的紫微/八字命盘 HTML 报告 |

截图方式：微信开发者工具打开 `miniprogram/`，在模拟器里进入对应页面，点工具栏相机图标即可导出 PNG。
